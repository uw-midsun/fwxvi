# Midnight Sun Telemetry Replay

A desktop application for viewing CAN telemetry from car SD-card logs.

## Requirements

- A C++17 compiler
- CMake 3.16 or newer
- Qt 6 with the Widgets module

## Build and run macOS

From the project directory, configure, build, and launch the app.

```sh
cmake -S . -B build
cmake --build build
./build/telemetry
```
