◆ pedal_calib_apply()

StatusCode pedal_calib_apply ( FrontControllerStorage *  storage)

Apply the pedal persist data to the pedal storage calibration.

Maps the values held in storage->pedal_persist_data (loaded from flash or freshly sampled during a calibration) into the accel/brake pedal calibration data, falling back to defaults where the persisted values are invalid. Call this after a successful calibration to make the new values take effect without a reboot.

Parameters
storagePointer to the front controller storage
Returns
STATUS_CODE_OK if the calibration data is applied successfully STATUS_CODE_INVALID_ARGS if storage is NULL
